# Marketing AI Chatbot (Streamlit)

## Setup

1. Extract the ZIP file.
2. Open `.streamlit/secrets.toml` and replace `YOUR_GEMINI_API_KEY` with your Gemini API key.
3. Open a terminal in this project folder and run:

```bash
pip install -r requirements.txt
```

4. Start the app:

```bash
streamlit run app.py
```

## Files
- `app.py`: Streamlit chatbot and Marketing knowledge base.
- `requirements.txt`: Required Python packages.
- `.streamlit/secrets.toml`: Gemini API key configuration.
